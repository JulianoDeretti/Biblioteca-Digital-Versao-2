# Biblioteca Digital

Sistema de biblioteca digital desenvolvido para simular o funcionamento de uma biblioteca real, permitindo o gerenciamento de livros, usuários e empréstimos.

O projeto possui diferentes áreas para usuários e funcionários, oferecendo recursos para controle do acervo e acompanhamento do histórico de leitura.

### Principais recursos

- Modo usuário;
- Modo funcionário;
- Sistema de autenticação;
- Validação de dados;
- Cadastro e gerenciamento de livros;
- Controle do acervo;
- Empréstimos;
- Devoluções;
- Histórico de leitura;
- Pesquisa e organização dos livros;
- Interface responsiva;
- Backend utilizando Node.js.

### Tecnologias

- HTML
- CSS
- JavaScript
- Node.js

### Objetivo

Desenvolver uma aplicação que represente o funcionamento de um sistema de biblioteca, reunindo gerenciamento de acervo, usuários e empréstimos em uma única plataforma.

> Projeto desenvolvido para estudo e prática de desenvolvimento web.
